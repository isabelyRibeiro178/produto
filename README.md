# Gerenciador de produtos [
    [terminal]
]
projeto realizado em grupo na sala de aula.
## Objetivo
compreender como funciona o trabalho em grupo em uma equipe de desenvolvedores, analistas e testers.
## Componentes 
### Lógica de Programação 
estamos desenvolvendo em grupo um algoritmo ultizando python 3.1x.
### Redes 
fazemos "deploy" do código em uma máquina virtual - ubuntu server
### Processo de desenvolvimento de software
registramos requisitos funcionais e não funcionais, realizamos e aprendemos sobre o básico de ci/cd
